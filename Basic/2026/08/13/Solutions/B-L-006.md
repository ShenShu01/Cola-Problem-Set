# B-L-006 题解

## 题目大意
（这题看着不难，实际上确实不难）

对给定的数据进行去重和排序

我去，这么简单，跟10号的题比完全是降维打击，被打的是这道题

### 思考过程
去重+排序 没了

直接开写

怎么去重？遍历数组里的每个元素，遇到相同的就删掉？这样也太麻烦了吧？

应该有现成的方法，问问AI，确实有,unique()

依旧现学现用

### 代码
```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
    int N;
    cin >> N;
    vector<int> a;

    //输入
    int temp;
    while (N-- && cin >> temp) {
        a.push_back(temp);
    }

    //先排序再把重复元素移到末尾最后去重
    sort(a.begin(), a.end());
    auto last = unique(a.begin(), a.end());
    a.erase(last, a.end());

    int sum = a.size();
    cout << sum << endl;
    for (int i = 0; i < sum; i++) {
        cout << a[i] << " ";
    }
    
    return 0;
}
```

### 后话
既然学长说要学一下set，那我就再写一版吧

```C++
#include <bits/stdc++.h>
using namespace std;

int main() {
    int N;
    cin >> N;
    set<int> a;

    int temp;
    while (N-- && cin >> temp) {
        a.insert(temp);
    }

    int sum = a.size();
    cout << sum << endl;
   
    for(auto i : a) {
        cout << i << " ";
    }

    return 0;
}
```

set确实好用啊
1. 不能存放重复元素
2. 自动升序排序
3. 不能修改内部元素，只能删除再插入
